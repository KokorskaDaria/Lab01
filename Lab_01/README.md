# Лабораторна робота №1 — Основи функціонального програмування у Python

**Варіант 7: Облік електроенергії.**

Програма розраховує споживання електроенергії за показниками лічильників, вартість за тарифною групою та суму до оплати з урахуванням пільги. Значення тарифів у прикладі умовні: `standard` — 4 грн/кВт·год, `night` — 2 грн/кВт·год; пільга — 25%.

## Структура

- `main.py` — точка входу; викликає `app.main()`.
- `core.py` — чисті функції розрахунків, типи даних, фабрика обробника `make_processor`.
- `app.py` — умовні тарифні та пільгові політики, демонстраційні дані, виведення квитанцій.
- `tests/test_core.py` — тести `pytest`.
- `requirements.txt` — інструменти тестування, типізації та перевірки стилю.
- `report/` — папка для готового звіту.

## Запуск

У терміналі з кореня папки `Lab_01`:

```bash
python -m pip install -r requirements.txt
python main.py
python -m pytest -v
```

Додаткові перевірки:

```bash
python -m mypy core.py app.py main.py
python -m black --check core.py app.py main.py tests/test_core.py
python -m ruff check core.py app.py main.py tests/test_core.py
```

Примітка: форматування вихідного коду не змінювалося; для автоматичного форматування можна виконати `python -m black .`.
